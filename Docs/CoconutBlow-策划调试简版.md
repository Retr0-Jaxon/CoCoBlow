# 椰子吹落 — 策划调试简版

> 给策划/关卡同学：知道「调什么、什么感觉、怎么验」即可，不用看代码。

---

## 玩什么

1. 树上长椰子（不会自己掉）
2. 拿吹风机对准吹 → 吹一阵后掉下来
3. 吹到地上再滚进发光池 → 椰子数量 +1

---

## 在哪儿调（Unity Inspector）

| 想调什么 | 选中谁 | 主要字段 |
|----------|--------|----------|
| 吹多久才掉、掉多猛 | 椰子树 `coconut tree_03...` | Release Wind Force Threshold、Release Impulse |
| 风有多强、多远、多好瞄准 | `HairDryer` | Wind Force、Wind Range、Wind Angle |
| **射程范围可视化（风锥）** | `HairDryer/Nozzle/RangeVisual` | Always Show Range、Fill Color（见下节） |
| 椰子有多沉、滑不滑 | 预制体 `TinyCoconut` | Mass、Drag |
| 多久长新椰子、最多几颗 | 椰子树（同上） | Spawn Interval、Max Active Coconuts |
| 椰子长在哪儿 | `SpawnPoint_01~05` | 直接拖位置 |

## 射程可视化 — `RangeVisual`

**路径：** `HairDryer` → `Nozzle` → **`RangeVisual`**

半透明**风锥**，用来直观看吹风机能吹多远、锥口有多宽。**锥体形状自动跟随** `HairDryer` 上的 **Wind Range**（长度）和 **Wind Angle**（开口），改 Range/Angle 时锥体会一起变。

| 看什么 | 对应关系 |
|--------|----------|
| 锥体**长度** | = **Wind Range**（能吹到的最远距离） |
| 锥体**开口大小** | = **Wind Angle**（越大口越宽、越好瞄准） |
| 锥体**朝向** | = 喷嘴 `Nozzle` 的朝向（风从喷嘴指出去） |

### 什么时候显示

| 情况 | 是否显示风锥 |
|------|----------------|
| 吹风机在地上，未拾取 | ✓ 显示 |
| 拾取后**按住左键**吹风 | ✓ 显示 |
| 拾取后没按左键 | ✗ 隐藏 |
| 勾选 **Always Show Range** | ✓ **一直显示**（调参推荐） |

### 策划常用设置（`RangeVisual` 组件）

| 字段 | 建议 | 作用 |
|------|------|------|
| **Always Show Range** | 调参时 **勾选** | Play 里一直看到风锥，改 Range/Angle 立刻对照 |
| **Fill Color** | 半透明蓝/青即可 | 锥体颜色；Alpha 越小越不挡视线 |
| **Fade Duration** | 默认 0.25 | 停吹后锥体淡出速度（一般不用动） |

### 用风锥调参（推荐流程）

1. 选中 `RangeVisual`，勾选 **Always Show Range**
2. 进入 **Play**，选中 `HairDryer`
3. 拖动 **Wind Range / Wind Angle**，看锥体能否**罩住树上椰子**
4. 满意后 **退出 Play**，在 Edit 模式把数值写回并保存场景

**经验：** 锥口应能盖住目标椰子，且长度够到树梢；太窄（Angle 小）难瞄准，太长（Range 大）容易误吹别的物体。

## 五个旋钮（最重要）

> **Range / Angle** 调的时候请开着 `RangeVisual` 风锥对照（见上一节）。

| 旋钮 | 现在大约 | 变大 → | 变小 → |
|------|----------|--------|--------|
| **吹落难度**（Threshold） | 120 | 要吹更久 | 更容易掉 |
| **掉落力度**（Impulse） | 2 | 弹更远，易飞天 | 更软、更像「掉下来」 |
| **风力**（Wind Force） | **242.6** ⚠️ | 吹动/吹落都变猛 | 吹不动 |
| **风距离**（Range） | 8 | 站更远也能吹 | 必须贴近 |
| **瞄准宽容**（Angle） | **11.5** ⚠️ | 不用瞄太准 | 必须对准 |

⚠️ 当前场景风力很大、瞄准很严，和「慢慢吹下来」的手感可能不匹配，建议和风阈值一起调。

---

## 推荐手感目标

- **吹落**：对准吹 **1~3 秒** 才掉（不是擦到就掉）
- **掉落**：**往下/斜下掉**，不要刚掉就飞上天
- **落地后**：还能被风吹着滚向池子
- **节奏**：场上大约 **3~5 颗** 椰子可玩，缺了会补

---

## 三步调试法

0. **先看风锥** → `RangeVisual` 勾选 Always Show Range，用锥体定 **Range + Angle**
1. **再定「多久掉」** → 只动 **Threshold** + **Wind Force**（两者联动，别只改一个）
2. **再定「掉的样子」** → 只动 **Release Impulse**（飞天就减小，太软就略增）
3. **最后定「地上好不好吹」** → 动 **Drag** 和 **Wind Force**

---

## 快速验（Play 模式）

| 检查 | 过关标准 |
|------|----------|
| 风锥能不能看见 | 地上或吹风时出现；调参时可常显 |
| 风锥能不能罩住椰子 | Range/Angle 与目标距离匹配 |
| 不吹会不会掉 | 不会 |
| 对准吹会不会掉 | 会，且不是秒掉 |
| 会不会飞天 | 不会明显往天上飞 |
| 进池加不加数 | HUD 数字 +1 |

---

## 出问题了改啥（一句话）

| 现象 | 改 |
|------|-----|
| 秒掉 | 阈值 ↑ 或 风力 ↓ |
| 吹不掉 | 阈值 ↓ 或 风力 ↑ |
| 飞天 | 掉落力度 ↓、Drag ↑ |
| 地上吹不动 | 风力 ↑ 或 Drag ↓ |
| 椰子不够 | 补货间隔 ↓ 或 上限 ↑ |

---

## 和程序对齐的两句话

- 掉落后有约 **0.3 秒** 不会被风顶飞（防冲天），策划一般不用改，除非仍飞天再让程序加长。
- 释放方向程序已做成 **偏下**，策划主要调 **Impulse / 风力 / 阈值** 即可。
